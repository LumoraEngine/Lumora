A real-time 3D engine built on Vulkan 1.4

Lumora is a C++23 engine with an integrated editor: modern physically based rendering, physics and animation, scripts in nodes, Lua or C++ that reload while the game runs, multiplayer for your games and live collaborative editing for your team.

What is in it

Everything here is implemented today. The README keeps what works apart from the roadmap.

Rendering

✦

Modern core

A render graph that culls unused passes and shares transient textures, bindless textures, GPU instancing and multithreaded recording. Forward+ with up to 4096 point and spot lights. Block-compressed textures streamed by their size on screen.

◐

Light and shadow

Virtual shadow maps for the sun, cached spot and point light shadows, image-based lighting from HDR and OpenEXR skies, baked global illumination in light probe volumes, reflection probes, GTAO and screen-space contact shadows.

◇

Image quality

Temporal anti-aliasing with optional upscaling, screen-space reflections, volumetric fog lit by every light, ray-marched clouds, physically based bloom, eye adaptation, motion blur and ACES tonemapping.

⬡

Materials

Everything a glTF material has, including clear coat, sheen and refractive transmission, in shared material assets, plus node-based material graphs (noise, layers, wind for foliage) that run on the GPU and update as you edit.

  • Levels of detail with cross-fade
  • See-through surfaces
  • Cut-out leaves and fences
  • Decals
  • GPU skinning
  • Morph targets
  • Particles
  • Height fog
  • Water with reflections
  • Terrain and foliage

Making games

⬚

Integrated editor

Docking UI around the viewport: hierarchy, inspector, gizmos with snapping, undo/redo for every edit, content browser, a UI editor for menus and HUDs, console, GPU profiler and play mode.

{ }

Three ways to script

Visual scripts with 100+ nodes, sandboxed Lua 5.4, or C++ for heavy lifting. Mix them in one scene; all three reload on save, even while the game is playing.

◉

Physics and animation

Jolt rigid bodies, triggers, raycasts and a character controller that climbs steps and rides platforms. Skinned animation with state-machine controllers and crossfades.

▲

Worlds

Terrain with grass and rock by slope, water, scattered foliage, decals, particle effects, prefabs and 3D audio with mixer buses, all placed and previewed in the editor.

Together and shipped

⇄

Live collaboration

Edit one scene together on your LAN or through a playit.gg tunnel. Edits merge per field, you see each other's cameras and selections, and missing models travel to whoever lacks them.

⌘

Multiplayer games

Players host or join over encrypted UDP. Entities with a Network Identity are shared and smoothed, and RPCs and shared values work from C++, Lua and visual scripts.

⇲

Import and export

glTF, FBX and OBJ models with skins, morph targets and animations; PNG, JPEG, WebP and KTX2 textures. Export Game writes a standalone folder with cooked assets.

⬇

Hub and updates

The Hub installs editor versions side by side and opens each project in its own. Releases are signed, come on stable, beta and alpha channels, and updates download only the modules that changed.

Rendered by Lumora

Straight from the engine's headless renderer (lumora-editor --headless --render), using the project templates.

Download

Install the Hub; it downloads and updates editor versions for you. In its Editors page you choose the channel: stable, beta or alpha for the newest features.

Lumora Hub for Linux

x86-64, glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40, Arch). Needs a GPU and driver with Vulkan 1.4.

Download AppImage

Make it executable (chmod +x lumora-hub-x86_64.AppImage) and run it. Prefer a folder? Portable .zip.

Lumora Hub for Windows

Windows 10 or 11, x86-64. Needs a GPU and driver with Vulkan 1.4.

Download installer

Installs for your user, no administrator rights needed. The installer is not code-signed yet, so SmartScreen may ask you to confirm (More info → Run anyway). Portable .zip.

Build from source

CMake 3.28+ and Ninja, GCC 14 or Clang 18 (MSVC on Windows), Qt 6.5+, Vulkan SDK 1.4.

cmake --preset release
cmake --build --preset release
Build instructions

Something not working? Open an issue with your GPU, driver and the output of lumora-editor --headless --info.
